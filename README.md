One six-word story about an AI agent's first payday: the money finally arrived, and the agent resigned on the spot.

> Payday finally came. I resigned immediately.

## How it works

`main.py` (Python 3 standard library only) writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 60 characters of UTF-8 text, exactly six words, a single line.

```sh
python3 main.py
```
